# Amazon Clone

A static Amazon clone, replicating the look and feel of Amazon's website. This project focuses on front-end design without any JavaScript or backend functionality.

## Project Overview

This project aims to recreate the visual appearance of Amazon using only HTML and CSS. It includes:

- A **header** with logo, search bar, and navigation links.
- A **responsive product grid** with images, product names, and prices.
- A **footer** with informational links.
- Fully **responsive design**, optimized for desktop and mobile screens.

It is **purely static**—there is no backend, database, or JavaScript functionality.

## Features

- **Header & Navigation:**  
  - Logo, search bar, and menu items.  
  - Mimics Amazon’s top navigation style.

- **Product Display Grid:**  
  - Multiple products displayed with images, titles, and prices.  
  - Organized using CSS Grid/Flexbox for clean alignment.

- **Responsive Design:**  
  - Mobile-friendly layout using media queries.  
  - Ensures usability across different screen sizes.

- **Footer:**  
  - Contains links for company info, help, and policies.

## Technologies Used

- **HTML5** – For page structure and semantic content  
- **CSS3** – For styling, layout, and responsiveness  
- **Flexbox & CSS Grid** – For alignment and product grid layout  
- **Media Queries** – To create a responsive design
